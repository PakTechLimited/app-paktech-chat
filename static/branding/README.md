## The mark decoded

- Outer hexagon = 6 DevSecOps phases
- Dashed middle ring = network trust boundary
- Solid inner hex = application core
- Chevron = speech bubble / chat
- Vertical stem = broadcast signal
- Six coloured nodes = one per phase
